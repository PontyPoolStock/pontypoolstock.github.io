Save your BLACK-AND-WHITE PontyPool logo here as exactly:

  pontypool-logo-bw.png

How to get it:
1. Take the black-and-white logo image from chat.
2. Save/convert it to PNG (not JPG).
3. Name it exactly pontypool-logo-bw.png and put it in this folder.
4. Restart the print agent (npm run print).

Until then receipts print a bold PONTYPOOL text header so nothing blocks.
Thermal printers can't print colour — that's why it must be the B&W version.
Any width 300-600px is fine; the agent shrinks it for 80mm paper.
